# O02 · ex04 · Khôi phục đúng một bảng

Tình huống: `users` bị sửa nhầm; cần lấy lại đúng bảng này từ bản dump đêm qua mà không đụng các bảng khác.

```bash
# DB đích trống: dựng cấu trúc rồi nạp riêng dữ liệu bảng users
docker exec sql-practice-pg createdb -U postgres r4
docker exec sql-practice-pg pg_restore -U postgres -d r4 -s /tmp/m.dump          # schema-only: 0.29 s
docker exec sql-practice-pg pg_restore -U postgres -d r4 -a -t users /tmp/m.dump # data-only, bảng users: 0.43 s
docker exec sql-practice-pg psql -U postgres -d r4 -Atc "select (select count(*) from users), (select count(*) from orders)"
# → 100000|0   (users có dữ liệu, orders vẫn trống)
```
Số đo thật: 0.29 s (schema) + 0.43 s (dữ liệu `users`, 100 000 dòng) so với 20.2 s nếu restore cả DB (ex03).

## Giải thích
- `-t bảng` chọn một bảng; `-a` chỉ lấy dữ liệu; `-s` chỉ lấy cấu trúc. Restore chọn lọc chỉ dùng được với định dạng custom/directory (plain thì phải tự `grep`/`sed` file SQL).
- **Không restore thẳng đè lên production**: nạp vào DB/schema tạm, so sánh, rồi `INSERT … SELECT` hoặc `UPDATE … FROM` đúng các dòng cần cứu. Restore đè bảng đang chạy mất cả những thay đổi hợp lệ từ lúc backup đến giờ.
- Bản dump logic chỉ cho trạng thái **tại lúc dump** (đêm qua): các thay đổi sau đó mất. Muốn khôi phục đến phút trước sự cố thì cần PITR (ex05).
