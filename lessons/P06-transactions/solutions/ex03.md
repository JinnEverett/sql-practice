# P06 · ex03: kết quả thật khi chạy

Hai session, B chạy `UPDATE p06.acct SET balance = balance + 50 WHERE id = 1` giữa hai lần đọc của A (Postgres 18.6).

| cách của A | lần đọc 1 | lần đọc 2 | kết luận |
|---|---|---|---|
| `BEGIN` (READ COMMITTED, mặc định) | 100 | **150** | **non-repeatable read** tái hiện được |
| `BEGIN ISOLATION LEVEL READ UNCOMMITTED` | 100 | **150** | Postgres coi như READ COMMITTED |
| `BEGIN ISOLATION LEVEL REPEATABLE READ` | 100 | 100 | snapshot cố định cho cả transaction |
| `BEGIN ISOLATION LEVEL SERIALIZABLE` | 100 | 100 | |
| READ COMMITTED + `SELECT … FOR SHARE` ở lần đầu | 100 | 100 | B phải **chờ** A commit, rồi mới cộng (balance cuối vẫn 150) |
