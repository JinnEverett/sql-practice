# P06 · ex04: kết quả thật khi chạy

B chạy `UPDATE p06.acct SET balance = balance + 50 WHERE id = 1` (commit ngay) giữa lúc A đọc (100) và lúc A ghi.

| cách của A | balance cuối | kết luận |
|---|---|---|
| ghi `SET balance = 130` (số app tự tính từ 100) | **130** | **lost update**: cập nhật +50 của B biến mất |
| ghi `SET balance = balance + 30` (READ COMMITTED) | **180** | đúng: UPDATE đọc phiên bản mới nhất của dòng |
| đọc bằng `SELECT … FOR UPDATE`, rồi ghi `130` | **180** | B chờ A commit rồi mới cộng 50 |
| `REPEATABLE READ` + `SET balance = balance + 30` | **150** | A bị `ERROR: could not serialize access due to concurrent update` (40001); cập nhật +30 của A mất nếu không retry |
